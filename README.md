# AI Engineer Demo — V6

This version keeps the working 1,000-paper arXiv collector and replaces the failed large JSON startup fetch with smaller public Markdown dataset pages. It also adds product-candidate extraction, GitHub star enrichment, richer diagnostics, workbook output, and architecture PDF generation.

## Run

```powershell
python -m pip install -r requirements.txt
python -m pytest
python main.py --mode collect
python make_architecture_pdf.py
```

Outputs are under `data/processed/`:
- `startups.csv`
- `products.csv`
- `research_papers.csv`
- `news.csv`
- `jobs.csv`
- `entity_mapping_log.csv`
- `ai_intelligence_graph.xlsx`

`architecture.pdf` is generated by `make_architecture_pdf.py`.

## Data integrity

No records are synthesized to satisfy counts. Startups and product candidates retain source URLs. News/jobs are filtered by timestamp and may legitimately be empty when no qualifying source records exist in the exact 24-hour window.

## Important scope note

The assignment asks for 1,000 products. The public startup dataset used here lists companies and their offerings; the product collector therefore labels these as **product candidates** and keeps that provenance explicit. Before submission, manually review the product tab and replace any candidate that does not meet the assignment's exact product definition with a source-verified product record.

Do not commit API keys. Put secrets only in a local `.env` file.
